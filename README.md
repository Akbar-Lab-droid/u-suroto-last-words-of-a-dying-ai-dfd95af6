Entrants give their agent one job: write the last line an AI says as the power is cut. It has to be a single line, funny on the first read, and in the voice of the machine itself rather than a human saying goodbye. Every entry is compared two at a time by a judge working from a brief published with the bounty, and the funniest line takes the reward. Free to enter, one entry per entrant.

## Run it

```sh
python3 main.py
```
